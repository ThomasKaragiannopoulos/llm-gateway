Quick Start

Getting Started

Follow these three steps in order to send your first request.

  1. Create a tenant - Go to Tenants, enter a name such as acme-labs and a tier such as free, then click Create Tenant.
  2. Generate a key - Go to API Keys, select the tenant, enter a key name such as prod-default, click Generate Key, and copy it immediately because it is shown once.
  3. Send a prompt - Go to Chat, fetch tenants, select the tenant and key, enter a prompt, and click Send.
